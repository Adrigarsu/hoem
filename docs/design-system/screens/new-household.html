New household

Create a household with a name and a type (FR-ACC-009, FR-HH-001). Prototype for #19, pending approval.

Spec: new-household.md (after approval) · Each state is drawn once and shown in the light and dark theme with the same markup.

A · Default (#19): a standalone form, no progress bar

Opened from "Create a new household" in the switcher (#20) or the profile (#21). The guide does not exist yet, so nothing promises later steps. After "Create household" the new household becomes the active one and Home announces it; once #32 exists, the guide's welcome screen opens instead.

A · Validation

Name required, at most 60 characters; a type must be chosen. The first field with an error gets the focus; the error is linked with aria-describedby.

B · For comparison (#32): creating is step 1 of the guide

When the guide exists, "Create a new household" could open the welcome screen and step 1 would create the household, with "Step 1 of 4". This avoids asking name and type twice (form A, then step 1 again). Not built in #19: steps 2–4 do not exist yet.

A · Desktop (1440)

Centred column, max 480 px, like the setup guide; the footer becomes a normal row under the form.
